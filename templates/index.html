💻 Developer Integration Snippets

Call this API from Python, cURL, or JavaScript
🐍 Python (requests) POST 
import requests

url = "http://localhost:8000/api/predict"
payload = {
    "make": "TOYOTA",
    "model": "CAMRY",
    "vehicle_class": "MID-SIZE",
    "engine_size": 2.5,
    "cylinders": 4,
    "transmission": "AS8",
    "fuel_type": "X"
}
res = requests.post(url, json=payload)
print(res.json())
📟 cURL Terminal POST 
curl -X POST \
  http://localhost:8000/api/predict \
  -H "Content-Type: application/json" \
  -d '{

    "vehicle_class": "MID-SIZE",
    "engine_size": 2.5,
    "cylinders": 4,

    "fuel_type": "X"
  }'
🌐 JavaScript (fetch) POST 
fetch('/api/predict', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    make: "TOYOTA",
    model: "CAMRY",
    vehicle_class: "MID-SIZE",
    engine_size: 2.5,
    cylinders: 4,
    transmission: "AS8",
    fuel_type: "X"
  })
})
.then(r => r.json())
.then(data => console.log(data));
